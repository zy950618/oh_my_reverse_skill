# Real Website Handling Playbook

This repository only records authorized Web/H5 observation, JS/runtime analysis, pure API replay, and business-data assertions.

Allowed work:

- readonly browser observation, screenshots, and network summaries;
- JS signature/runtime parity analysis;
- official documentation review;
- authorized pure HTTP/API replay with final business-data assertions;
- fingerprint and block-reason diagnostics as observation, not evasion.

Forbidden work:

- visual challenge solving or verification automation;
- action replay for visual challenges;
- token forgery, clearance reuse, proxy evasion, webdriver hiding, or fingerprint spoofing;
- using local labs or historical fixtures as proof of production capability.

Positive capability requires an in-scope target, direct interface repeat, fresh evidence, and `business_data_status=DATA_ASSERTION_PASS`.
